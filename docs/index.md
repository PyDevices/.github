# .github docs

This repository holds the pieces every PyDevices repository shares: the
community health files, the reusable release workflows, the org portal's
repository database and the shared documentation setup. These pages are for
people who maintain those pieces or release a package with them.

**Get started.** [Set up a checkout](get-started/set-up.md) and run its
checks, then [cut your first release](get-started/first-release.md) of a
package.

**Guides.** [Release a package](guides/release-a-package.md),
[publish to production PyPI](guides/publish-to-pypi.md),
[roll back a release](guides/roll-back-a-release.md),
[fix a release that failed](guides/fix-a-failed-release.md),
[build and publish documentation](guides/build-and-publish-docs.md),
[write docstrings](guides/write-docstrings.md) and
[keep to the maintenance schedule](guides/maintenance-schedule.md).

**Reference.** [Workflows](reference/workflows.md), the
[release workflows' inputs, secrets and tags](reference/release-workflows.md),
[repository layout](reference/repo-layout.md),
[heading emoji](reference/heading-emoji.md) and
[where things live on GitHub](reference/github-org.md).

**How it works.** [What this repository is](how-it-works/overview.md),
[the release chain](how-it-works/release-chain.md),
[design principles](how-it-works/design-principles.md) and
[platform support tiers](how-it-works/platform-support-tiers.md).

**Changelog.** This repository has no versions of its own; the reusable
workflows are versioned by `publishing-vN` tags, listed under
[tags](https://github.com/PyDevices/.github/tags). What is planned is in
[ROADMAP.md](../ROADMAP.md). To contribute, read
[CONTRIBUTING.md](../CONTRIBUTING.md).
