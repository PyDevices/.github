# audioinstruments

Playable synthesizers, organs, electric pianos and drum machines, each one a patch of modules on a virtual rack, rendered a block at a time on audiodsp. Pure Python on CPython and MicroPython-compatible firmware. It is on TestPyPI as `omnipython-audioinstruments` and in the MIP index as `audioinstruments`.

[audioinstruments on GitHub](https://github.com/PyDevices/audioinstruments).
