# pydevices

The core of PyDevices: the display engine, the hardware drivers and the board configurations that let one program run on many boards. It holds `displaydev`, `audiodev`, `appdev`, `multimer`, `events` and `keys`, the USB packages, and the sources of palettes and pdwidgets. Start here when you want to put something on a screen.

[pydevices on GitHub](https://github.com/PyDevices/pydevices).

Its manual is the set of Markdown pages in its `docs/` folder on GitHub.
