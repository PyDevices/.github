# pygraphics

Drawing primitives, bitmap font rendering, paletted surface blitting and dirty-area tracking. The core is C for speed on a microcontroller, with a pure-Python version that behaves the same, so a program draws the same on a board, a desktop and a browser tab.

[Read the pygraphics manual](https://pydevices.readthedocs.io/projects/pygraphics/en/latest/).
