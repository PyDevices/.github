# audioeffects

Studio and guitar-pedal effects: compressors, EQs, reverbs, delays, modulation, drive and amp simulation, pitch shifters and racks. Pure Python on audiodsp's audio nodes. It is on TestPyPI as `omnipython-audioeffects` and in the MIP index as `audioeffects`.

[audioeffects on GitHub](https://github.com/PyDevices/audioeffects).
