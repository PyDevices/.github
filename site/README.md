# Org landing site (source)

Canonical source for <https://pydevices.github.io/>.

Edit files here in [PyDevices/.github](https://github.com/PyDevices/.github)
(`site/`). GitHub Actions deploys this tree to
[PyDevices/PyDevices.github.io](https://github.com/PyDevices/PyDevices.github.io)
on every push to `main` that touches `site/` — that publish-only repo exists
solely because GitHub requires the name `PyDevices.github.io` for the org
apex URL. Do not edit the publish repo by hand.
