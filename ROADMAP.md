# Roadmap

Where the org's shared release automation and community files are heading.
Bugs, and things you need that don't work yet, go to
[issues](https://github.com/PyDevices/.github/issues).

## Release automation

- A manual way to tag a release when GitHub drops the merge event. Every
  repository that calls the shared tagging workflow gets it by adding one
  trigger line, instead of carrying its own copy of the fix.
